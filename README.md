Python Basic Calculator

A beginner-friendly calculator built using Python.

Features

- Addition
- Subtraction
- Multiplication
- Division
- User input handling
- Basic error handling for division by zero

Technologies Used

- Python
- Visual Studio Code

Purpose

This project was created to practice Python fundamentals and improve problem-solving skills as a beginner programmer.

How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the program using:

python cal.py
